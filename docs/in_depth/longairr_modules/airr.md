# LongAIRR airr module

`longairr airr` assigns V(D)J genes to consensus sequences and generates
AIRR-compatible tabular output. Immunoglobulin and T-cell receptor sequences
are processed separately.

## How it works

LongAIRR uses IgBLAST and Change-O to:

1. assign germline V, D and J genes;
2. convert the annotation to AIRR format;
3. optionally retain productive sequences;
4. optionally create a productive immunoglobulin heavy-chain subset.

The command accepts consensus FASTA output directly or the passing/split FASTA
files generated by `longairr seqtag`.

## Required references

Two database paths are required:

- the IgBLAST database directory;
- the species-specific IMGT germline `vdj` directory.

These references can be downloaded during
[LongAIRR installation and setup](../../getting_started/installation.md#extra-dependencies).

## Usage

```text
longairr airr [OPTIONS] inputdir_igblast inputdir_germlines input_seqs outdir
```

| Argument | Description |
| --- | --- |
| `inputdir_igblast` | IgBLAST database directory |
| `inputdir_germlines` | Species-specific IMGT germline `vdj` directory |
| `input_seqs` | FASTA containing sequences to annotate |
| `outdir` | Run- or sample-level output directory |

!!! important
    The positional input and output arguments are order-sensitive.

## Main options

| Option | Description | Default |
| --- | --- | --- |
| `--loci` | Receptor locus: `ig` or `tr` | `ig` |
| `--ph` | Generate productive output and, for IG, a productive-heavy subset | `TRUE` |
| `--sample` | Sample identifier for sample-level bulk metadata | Not set |
| `--run-root` | Explicit run root for structured metadata | Auto-detected |

## Immunoglobulin example

```bash
longairr airr \
  --loci ig \
  /path/to/databases/igblast/ \
  /path/to/databases/germlines/imgt/human/vdj/ \
  input_ig.fasta \
  /path/to/longairr_results/
```

## T-cell receptor example

```bash
longairr airr \
  --loci tr \
  /path/to/databases/igblast/ \
  /path/to/databases/germlines/imgt/human/vdj/ \
  input_tr.fasta \
  /path/to/longairr_results/
```

For demultiplexed bulk data, also provide the sample identifier:

```text
--sample UID6
```

## Main outputs

With `--ph true`, LongAIRR writes:

```text
airr/ig_p_parse-select.tsv
airr/ig_ph_parse-select.tsv
airr/tr_p_parse-select.tsv
```

Only the files relevant to the requested locus are generated.
`ig_ph_parse-select.tsv` contains productive immunoglobulin sequences with an
IGHV assignment. If `--ph false`, the unfiltered valid AIRR table is retained
as `ig_db-pass.tsv` or `tr_db-pass.tsv`.

!!! important
    The four positional arguments are order-sensitive.
